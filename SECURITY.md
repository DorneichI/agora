# Security Policy

## Supported Versions

This project does not yet have a formal release/versioning scheme. Only the `main` branch is
supported — please ensure you're reporting against the latest code on `main`.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting flow:

[Report a vulnerability](https://github.com/DorneichI/agora/security/advisories/new)

This creates a private security advisory visible only to the maintainer, so the issue isn't
disclosed publicly before a fix is available.

When reporting, please include as much of the following as you can:
- The affected component (`backend`, `web`, or `mobile`)
- Steps to reproduce
- The potential impact

## Response Time

This is an early-stage, largely solo-maintained project. Reports will be acknowledged and
investigated on a best-effort basis — there is no guaranteed response-time SLA.
